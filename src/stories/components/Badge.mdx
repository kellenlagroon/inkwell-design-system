# Badge

A compact count / notification indicator. Show a small count or short label, or
set `dot` for a bare presence indicator — the generalization of the app's nav
notification dot.

**Status:** [Stable](?path=/docs/component-status-status--docs) · **Accessibility:** Meets standards

## When to use

- Use for an unread/new count or a small status number, usually attached to an icon, nav item, or control.
- Use `dot` for a bare "there's something new" indicator with no number.
- Use [Pill](?path=/docs/components-pill-docs--docs) instead for an inline status **label** (Published, Open, …).

## Usage guidance

- Do keep the content to a short count or 1–2 characters (e.g. `9`, `99+`).
- Do position badges on controls with a relative wrapper, not by baking offsets into the component.
- Don’t use Badge for a status word — that’s `Pill`.

## Keyboard and accessibility

- In `dot` mode there's no text, so give it an `aria-label` when it carries meaning, or `aria-hidden` when it's decorative.
- A count badge on an icon control still needs the control itself to have an accessible name.
