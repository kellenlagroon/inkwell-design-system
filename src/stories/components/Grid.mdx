# Grid

Equal-column layout with a token-backed gap. `Grid` uses the app's
`repeat(n, minmax(0, 1fr))` convention, so columns stay equal and never overflow
their track when content is wide.

**Status:** [Stable](?path=/docs/component-status-status--docs) · **Accessibility:** Meets standards

## When to use

- Use for evenly divided columns: card grids, stat rows, option matrices.
- Use [Stack](?path=/docs/layout-stack--docs) for vertical flow and [Inline](?path=/docs/layout-inline--docs) for items that should wrap rather than hold a column count.
- For bespoke templates (e.g. `content + trailing auto`), use a plain element with custom CSS.

## API

<ArgTypes of={GridStories} />

`columns` sets the number of equal columns (`repeat(n, minmax(0, 1fr))`, default
2). `gap` uses the shared spacing scale (default `md`/12px). All native `div`
props pass through.

## Usage guidance

- Do use `Grid` when you want columns of equal width.
- Do reach for [Inline](?path=/docs/layout-inline--docs) instead when items should wrap freely rather than hold a fixed column count.
- Don’t use `Grid` for a single column — use `Stack`.

## Keyboard and accessibility

- `Grid` is a layout wrapper and renders a plain `div`; it adds no semantics.
- DOM order is the reading and tab order — keep it meaningful, since the grid only affects visual placement.
