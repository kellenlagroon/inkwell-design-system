# Typography utilities

Typography tokens and semantic HTML are the default path for app copy. `Text`,
`Heading`, and `Link` remain optional utilities where their small conveniences
are useful.

These utilities are not part of the primary component catalog.

## When to use

- Start with semantic HTML: `<p>`, heading elements, `<strong>`, and `<a>`.
- Apply the documented typography and semantic color tokens directly.
- Use `Text` only for optional tone, safe wrapping, truncation, or line clamping.
- Use `Heading` and `Link` when their small API is more convenient than direct HTML.

## Wrapping

`Text` wraps at word boundaries like a normal paragraph. Set `wrap="anywhere"` for
strings with no break opportunities — emails, URLs, ids — where overflow is a real
risk. Applying it everywhere breaks ordinary prose mid-word, and it also changes how
the element contributes to a flex or grid track's minimum size.

## Token-first usage

- Body copy: `--font-size-body`, `--font-weight-ui`, and `--line-height-body`.
- Labels and helper text: `--font-size-label`, `--font-weight-label`, and `--line-height-label`.
- Headings: a heading-scale size with the display family/weight and `--line-height-heading`.
- Use semantic color tokens such as `--color-text-primary` and `--color-text-secondary`; reserve status colors for status meaning.
- Don’t use heading-scale text inside compact controls or panels.
