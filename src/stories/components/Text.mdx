# Text

Text primitives for app copy: `Text`, `Heading`, and `Link`.

**Status:** [Beta](?path=/docs/component-status-status--docs) · **Accessibility:** Not reviewed

## When to use

- Use `Text` for common body, muted, strong, and semantic text.
- Use `Heading` for local content hierarchy.
- Use `Link` for inline navigation and external anchors.

## Usage guidance

- Do use these primitives when consumers would otherwise reach for raw CSS.
- Do keep headings proportional to their surrounding surface.
- Don’t use heading-scale text inside compact controls or panels.
