# FieldGroup

A responsive grid for related form fields and aligned actions.

**Status:** [Beta](?path=/docs/component-status-status--docs) · **Accessibility:** Not reviewed

## When to use

- Use when two to four related fields should read as one row.
- Use for filter rows with an aligned submit/apply action.
- Use `Stack` for unrelated fields in a vertical form.

## Usage guidance

- Do keep grouped fields semantically related.
- Do let it collapse to one column on mobile widths.
- Don’t use it for whole-page layout.
