# Surface

Layout surfaces and simple page containers: `Container`, `Center`, `Surface`,
and the `Paper` alias.

**Status:** [Beta](?path=/docs/component-status-status--docs) · **Accessibility:** Not reviewed

## When to use

- Use `Container` for page-width constraints.
- Use `Center` for centered auth or empty layouts.
- Use `Surface`/`Paper` for framed panels that are not item cards.

## Usage guidance

- Do use `Card` for repeated content items.
- Do use `Surface` for framed task panels.
- Don’t nest cards inside cards for page layout.
