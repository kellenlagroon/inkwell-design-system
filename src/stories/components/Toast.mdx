# Toast

An ephemeral notification surface for lightweight confirmation and alert messaging that should not interrupt the current flow.

**Status:** [Stable](?path=/docs/component-status-status--docs) · **Accessibility:** Reviewed

## When to use

- Use `Toast` for short-lived feedback that does not need to occupy the main layout.
- Keep copy concise and strongly scannable.
- Treat `ToastRegion` as infrastructure rather than a separate catalog component in this pass.

## Usage guidance

- Do keep toast copy brief and directly relevant to the triggered action.
- Do use inline or persistent feedback instead when the user needs to act on the message in place.
- Do keep region behavior consistent across the application.
- Don’t use toasts for complex instructions.
- Don’t rely on transient feedback for critical state changes.

## Keyboard and accessibility

- Toasts should remain understandable without color alone.
- Dismiss actions should be reachable when present.
- Region announcements should stay concise to avoid overwhelming assistive technology users.
