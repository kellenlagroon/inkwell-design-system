# Divider

A thin hairline rule that separates content. Generalizes the app's `border-bottom`
row dividers and the split-button rule into one primitive.

## When to use

- Use to separate stacked sections or inline groups.
- Use a `label` to break a stack with a word (e.g. "or" between auth options).
- For spacing alone (no visible line), use the layout primitives instead.

## API

<ArgTypes of={DividerStories} />

`orientation` is `horizontal` (default, a native `<hr>`) or `vertical` (an inline
rule that needs a flex/grid parent to take height). `label` renders a centered
label between two lines. The rule carries no margins — space it with layout
primitives.

## Accessibility

- The horizontal rule is a native `<hr>` (implicit `role="separator"`, horizontal orientation).
- The vertical and labeled variants use `role="separator"`; vertical adds `aria-orientation="vertical"`.
