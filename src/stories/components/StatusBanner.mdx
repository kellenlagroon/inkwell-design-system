# StatusBanner

An inline feedback surface for success, warning, and error communication near the active task.

**Status:** [Stable](?path=/docs/component-status-status--docs) · **Accessibility:** Meets standards

## When to use

- Use `StatusBanner` for contextual system feedback inside the current view.
- Prefer it over a toast when the user needs the message to stay attached to nearby content.
- Use dismissible behavior only when clearing the message is safe.

## Usage guidance

- Do keep the message short and actionable.
- Do place the banner close to the content or task it refers to.
- Do use tone consistently with system severity.
- Don’t rely on banner tone alone to convey meaning.
- Don’t dismiss a banner automatically if the user still needs the context.

## Keyboard and accessibility

- Dismiss buttons must be reachable and clearly labeled.
- Banner content should remain understandable without color cues.
