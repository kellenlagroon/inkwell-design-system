# Panel

A presentational surface for grouped content, section headings, and empty states.

## When to use

- Use `Panel` to separate a block of content from the surrounding page.
- Use `SectionHeading` when that block needs a title, copy, or actions.
- Use `EmptyState` when the section has no data yet.
