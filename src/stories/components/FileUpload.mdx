# FileUpload

A native file input with trigger, dropzone, removable file-item, and validation
options. The consuming app owns upload behavior, validation, and storage.

**Status:** [Beta](?path=/docs/component-status-status--docs) · **Accessibility:** Not reviewed

## When to use

- Use for selecting a local file before an app-owned upload.
- Pair with `FormField` for label, hint, error, and required wiring.
- Keep validation messages specific to file type, size, or upload state.

## Usage guidance

- Do pass `accept` when the workflow requires a specific file type.
- Do leave upload side effects in the consuming app.
- Use `onFilesChange` to keep selected-file state in sync with a consuming flow.
- Don’t hide validation errors in helper copy.

## Keyboard and accessibility

- The hidden input remains associated with the `FormField` label.
- The visible trigger is a button and can be activated by keyboard.
- Dropzones support click, Enter, Space, and drag-and-drop selection.
- Each styled file item has a named remove action; use `clearable={false}` when
  the consuming workflow should prevent removal.
