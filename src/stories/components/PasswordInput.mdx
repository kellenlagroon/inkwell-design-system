# PasswordInput

A password field with an accessible visibility toggle. It shares `FormField`
wiring with `TextInput`.

**Status:** [Beta](?path=/docs/component-status-status--docs) · **Accessibility:** Not reviewed

## When to use

- Use for password, access-code, and secret inputs.
- Set `autoComplete` to `current-password` or `new-password` for auth flows.
- Use `TextInput` for non-secret text.

## Usage guidance

- Do provide a visible `FormField` label.
- Do use autocomplete values that match the auth workflow.
- Don’t use the reveal toggle as a substitute for clear validation messages.

## Keyboard and accessibility

- The reveal control is a native button with `aria-pressed`.
- `FormField` supplies label, required, hint, and error wiring.
