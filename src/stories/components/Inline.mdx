# Inline

Horizontal flow with token-backed gap, wrapping, and alignment. Use it for
button rows, toolbars, tag lists, and any set of items that sit side by side.

**Status:** [Stable](?path=/docs/component-status-status--docs) · **Accessibility:** Reviewed

## When to use

- Use for horizontally arranged items that need even spacing.
- Use for groups that should wrap gracefully on narrow widths (the default).
- Use [Stack](?path=/docs/components-stack-docs--docs) for vertical flow, [Grid](?path=/docs/components-grid-docs--docs) for aligned columns.

## API

<ArgTypes of={InlineStories} />

`gap` uses the shared spacing scale (default `md`/12px). `align` maps to
`align-items` (default `center`), `justify` to `justify-content`, and `wrap`
toggles `flex-wrap` (default `true`). All native `div` props pass through.

## Usage guidance

- Do use `Inline` for action rows so button spacing is consistent across the system.
- Do keep `wrap` on for anything that could overflow on small screens.
- Do use `justify="between"` to push a trailing action to the far edge.
- Don’t set `wrap={false}` unless clipping/overflow is genuinely intended.

## Keyboard and accessibility

- `Inline` is a layout wrapper and renders a plain `div`; it adds no semantics.
- Order children in the DOM to match the intended reading and tab order.
