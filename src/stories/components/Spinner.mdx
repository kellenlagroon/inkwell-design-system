# Spinner

A small rotating indeterminate loader for short waits inside a control or beside
a label. For loading larger regions of content, use
[Skeleton](?path=/docs/components-skeleton-docs--docs) so the layout doesn't
jump when data arrives.

## API

<ArgTypes of={SpinnerStories} />

`size` is `sm` | `md` (default) | `lg`. `tone` is `muted` (default), `brand`,
or `current` (inherits `currentColor` — pair with a colored container). Pass
`decorative` when a surrounding region already announces the loading state.

## Accessibility

- Renders `role="status"` with `aria-live="polite"` and an sr-only `label` (default "Loading").
- Pass `decorative` to skip the announcement when the surrounding region carries it.
- Rotation animation is slowed under `prefers-reduced-motion: reduce`.
