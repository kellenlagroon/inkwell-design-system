# Spinner

A small rotating indeterminate loader for short waits inside a control or beside
a label. For loading larger regions of content, use
[Skeleton](?path=/docs/components-skeleton--docs) so the layout doesn't
jump when data arrives.

**Status:** [Beta](?path=/docs/component-status-status--docs) · **Accessibility:** Not reviewed

## When to use

- Use for short in-place waits inside a control or beside a label (e.g. a button in a loading state).
- For larger regions of content, use [Skeleton](?path=/docs/components-skeleton--docs) so the layout doesn't jump when data arrives.
- For a task with known progress, use [Progress](?path=/docs/components-progress--docs) instead.

## Usage guidance

- Do use spinners for brief, localized waits.
- Do pair the spinner with visible loading text when the wait may last more than a moment.
- Do use `decorative` when the surrounding button or region already communicates loading.
- Don’t use a spinner for known progress or full-page content loading.

## Keyboard and accessibility

- Renders `role="status"` with `aria-live="polite"` and an sr-only `label` (default "Loading").
- Pass `decorative` to skip the announcement when the surrounding region carries it.
- Rotation animation is slowed under `prefers-reduced-motion: reduce`.
