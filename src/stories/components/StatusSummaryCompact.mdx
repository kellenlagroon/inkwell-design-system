# StatusSummaryCompact

A compact row of labelled status values, optionally paired with expandable detail.

**Status:** [Beta](?path=/docs/component-status-status--docs) · **Accessibility:** Not reviewed

## When to use

- Use for small health/status summaries.
- Use neutral item labels and semantic tones.
- Keep domain-specific meaning in the consuming app.
