# StatusSummaryCompact

A compact, wrapping layout region for status metadata. It intentionally does not
prescribe item structure or disclosure behavior.

**Status:** [Beta](?path=/docs/component-status-status--docs) · **Accessibility:** Not reviewed

## When to use

- Use for small health/status summaries.
- Compose items with `Inline` and `Pill`, using the status treatment that fits the page.
- Keep domain-specific meaning in the consuming app.

## Usage guidance

- Do keep labels short and use token-backed layout primitives for each item.
- Do wrap the summary in `Collapsible` when the page needs expandable detail.
- Don’t encode app-specific statuses or disclosure behavior into this layout primitive.
