# List

A grid-based list of rows — not a semantic table. Use for content that reads
tabularly but isn't structured data (directorys, submission summaries, action rows).
Seeded from the app's `directory-table` pattern.

**Status:** [Beta](?path=/docs/component-status-status--docs) · **Accessibility:** Not reviewed

## When to use

- Use for stacked rows where each row has a consistent column layout but the content is heterogeneous (avatars, buttons, blocks of copy).
- For structured data with sortable columns and cells, use [Table](?path=/docs/components-table--docs) instead.

## API

<ArgTypes of={ListStories} />

`columns` is a CSS `grid-template-columns` string — e.g. `"1fr auto"` or
`"minmax(0, 1.1fr) minmax(0, 1fr) auto"`. It's applied to every row via the
`--ink-list-cols` custom property. Compose rows with `<List.Row>`; each child of
a row becomes a grid cell.

## Usage guidance

- Do keep the column template consistent across every row in a list.
- Do use `minmax(0, 1fr)` for text-heavy columns so content can truncate or wrap predictably.
- Do place row actions in the trailing column when the list supports per-item management.
- Don’t use List for sortable, comparable data; use Table instead.

## Keyboard and accessibility

- The wrapper carries `role="list"`; each row is `role="listitem"`.
- Rows are visual containers — put any interactive controls inside as normal.
