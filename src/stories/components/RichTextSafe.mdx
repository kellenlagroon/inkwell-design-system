# RichTextSafe

A styled container for already-sanitized rich HTML.

**Status:** [Beta](?path=/docs/component-status-status--docs) · **Accessibility:** Not reviewed

## When to use

- Use for trusted, sanitized descriptions that include headings, lists, and links.
- Keep sanitization in the consuming app.
- Compose collapsed behavior with app-level controls when expansion is needed.

## Usage guidance

- Do sanitize HTML before rendering it.
- Do use regular React children when content is app-authored.
- Don’t pass unsanitized third-party HTML.
