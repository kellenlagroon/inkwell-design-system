# CheckboxSelect

A multi-select filter popover built from checkboxes.

**Status:** [Beta](?path=/docs/component-status-status--docs) · **Accessibility:** Not reviewed

## When to use

- Use when users need to select multiple filter values from a compact control.
- Keep `value` and apply/close behavior consumer-owned.
- Use plain `Checkbox` groups when space is available inline.

## Usage guidance

- Do use concise option labels.
- Do include search only when the list is long enough to need it.
- Don’t bake domain concepts into the option model.
