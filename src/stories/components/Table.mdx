# Table

A semantic HTML `<table>` with optional sortable columns, sticky header, row
hover, and density presets. Sort state is caller-controlled: the component
surfaces the click and shows the indicator, but you sort the data yourself.

**Status:** [Beta](?path=/docs/component-status-status--docs) · **Accessibility:** Baseline

## When to use

- Use for genuinely tabular data — comparing values across rows.
- For non-tabular content that still reads as rows (e.g. the app's roster), use [List](?path=/docs/components-list-docs--docs) instead.

## API

<ArgTypes of={TableStories} />

Columns are `{ id, header, render, sortable?, align?, width? }`. `render` gets
each row and returns the cell content. `align` is `"start" | "center" | "end"`
(default start). Set `width` for a `<colgroup>` sized column (e.g. `"12ch"`).

Sort is caller-controlled: pass `sortBy` + `sortDirection` + `onSortChange`, and
sort the `data` array yourself. Or use `defaultSortBy` for uncontrolled UI state
only (the data still needs to be pre-sorted).

## Keyboard and accessibility

- Renders a native `<table>` with `<thead>`/`<tbody>` and `<th scope="col">` headers.
- Sortable headers use `aria-sort` (`ascending` | `descending` | `none`) and expose the click as a native button.
- Empty state renders as a single spanning `<td>` so the row still parses as a table row.
