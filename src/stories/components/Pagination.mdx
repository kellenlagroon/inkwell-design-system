# Pagination

Page navigation with callback and link-backed modes.

**Status:** [Beta](?path=/docs/component-status-status--docs) · **Accessibility:** Not reviewed

## When to use

- Use for server-backed or paged result sets.
- Use `getPageHref` when pagination should be link navigable.
- Use `onPageChange` when pagination is client controlled.
