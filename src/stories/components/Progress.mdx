# Progress

A circular SVG progress ring with rounded caps. Determinate progress has an animated
wavy silhouette; the indeterminate ring is smooth and rotates. Pass `value` (0–100)
for determinate progress; omit it for an indeterminate animated ring.

**Status:** [Beta](?path=/docs/component-status-status--docs) · **Accessibility:** Not reviewed

## When to use

- Use for long-running single-task progress (uploads, syncs, downloads) where the user needs to see how far along it is.
- Omit `value` for an indeterminate bar when the duration is unknown.
- For short in-place waits, use [Spinner](?path=/docs/components-spinner--docs) instead.

## API

<ArgTypes of={ProgressStories} />

`value` is optional — omit for indeterminate. `tone` is `brand` (default),
`success`, or `danger`. `size` is `md` (default, 10px) or `sm` (7px). When
`label` is set, it's rendered above the bar and used as the accessible name; the
value is shown alongside via `valueFormatter` (defaults to `${value}%`).
Without a label, provide `ariaLabel`.

## Usage guidance

- Do use determinate progress when the app can calculate meaningful completion.
- Do use indeterminate progress when work is active but the duration is unknown.
- Do pair unlabeled bars with a clear `ariaLabel`.
- Don’t use progress bars for short button-level waits; use Spinner instead.

## Keyboard and accessibility

- Renders `role="progressbar"` with `aria-valuemin="0"` and `aria-valuemax="100"`.
- Determinate bars set `aria-valuenow`; indeterminate bars set `aria-valuetext="indeterminate"`.
- Labeled bars use `aria-labelledby`; unlabeled bars need an `ariaLabel`.
- Values passed via `value` are clamped to 0–100 and rounded to a whole percent.
- Under `prefers-reduced-motion: reduce`, wavy-path and indeterminate motion stop.
