# Popover

An anchored surface for compact content and action menus.

**Status:** [Beta](?path=/docs/component-status-status--docs) · **Accessibility:** Meets standards

## When to use

- Use the default `content` mode for filter panels, compact forms, and supporting controls.
- Use `mode="menu"` with `PopoverMenuItem` for a small set of actions.
- Use `Drawer` when the content needs persistent space or mobile full-height treatment.

## Usage guidance

- Do provide a trigger with a clear label.
- Do keep content compact.
- Do use `mode="menu"` only for a list of immediate actions.
- Don’t bury multi-step work inside a popover.

## Keyboard and accessibility

- Escape closes the popover and returns focus to the trigger; outside pointer interaction closes it too.
- Menu mode exposes `role="menu"`; Arrow keys, Home, and End move between its items, and Tab closes it.
- Mobile sheet mode uses a labelled dialog, a backdrop, initial focus, and a contained Tab sequence.

`PopoverMenu` remains exported as a deprecated compatibility wrapper. New work should use `Popover`.
