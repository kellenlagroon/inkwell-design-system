# Button

A clickable action control for primary, secondary, destructive, and low-emphasis actions. Set `variant` for the role and `size` for density; any extra `className` is appended for composition.

**Status:** [Stable](?path=/docs/component-status-status--docs) · **Accessibility:** Meets standards

## When to use

- Use `Button` when the user needs to trigger a clear next step or confirmation.
- Use `IconButton` only when the surrounding context makes the action obvious without a text label.
- Use visual hierarchy intentionally so one action reads as primary.

### Size

Scale button density based on surrounding UI, not just label length.

The default `md` button has a 40 px minimum height, 14 px text, 16 px inline
padding, and an 8 px content gap. The `sm` button has a 36 px minimum height
with the same text and 16 px icon size. Both sizes use 4 px corners.
On coarse pointers the minimum height rises to 44 px. Use `startIcon` and
`endIcon` for decorative icons. Button links use the same metrics.

### Text button

Use `TextButton` for an in-place action that should read visually as a link,
such as a disclosure. It keeps native button semantics; use `Link` for navigation.

### Text disclosure

Use `TextDisclosure` for a controlled show/hide action. It switches labels and
wires `aria-expanded` plus `aria-controls`; the parent owns the target content
and expanded state. Use `Collapsible` instead when Inkwell should own a complete
header-and-content disclosure region.

## Usage guidance

- Do keep labels short, task-oriented, and written in sentence case.
- Do use one primary button in a cluster whenever possible.
- Do pair destructive intent with explicit danger styling.
- Don’t place multiple primary buttons side by side in the same action group.
- Don’t rely on icons alone when the action meaning could be ambiguous.

## Keyboard and accessibility

- `Tab` moves focus to the button.
- `Enter` activates the focused button.
- `Space` activates the focused button.
- Icon-only buttons should always provide an accessible name.
- `TextDisclosure` names the controlled content and exposes its current state.
- `IconButton` has a 44 px default size and a 36 px `sm` size. Both have a
  44 px minimum target on coarse pointers.
