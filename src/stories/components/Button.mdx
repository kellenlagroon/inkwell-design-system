# Button

A clickable action control for primary, secondary, destructive, and low-emphasis actions. Set `variant` for the role and `size` for density; any extra `className` is appended for composition.

**Status:** [Stable](?path=/docs/component-status-status--docs) · **Accessibility:** Meets standards

## When to use

- Use `Button` when the user needs to trigger a clear next step or confirmation.
- Use `IconButton` only when the surrounding context makes the action obvious without a text label.
- Use visual hierarchy intentionally so one action reads as primary.

## Usage guidance

- Do keep labels short, task-oriented, and written in sentence case.
- Do use one primary button in a cluster whenever possible.
- Do pair destructive intent with explicit danger styling.
- Don’t place multiple primary buttons side by side in the same action group.
- Don’t rely on icons alone when the action meaning could be ambiguous.

## Keyboard and accessibility

- `Tab` moves focus to the button.
- `Enter` activates the focused button.
- `Space` activates the focused button.
- Icon-only buttons should always provide an accessible name.
