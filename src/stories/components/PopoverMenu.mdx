# PopoverMenu

An anchored lightweight menu surface for account actions and row-level utility actions.

## When to use

- Use `PopoverMenu` when the trigger and menu actions are tightly related.
- Use it for small action sets that should stay visually attached to the trigger.
- Move multi-step or workflow-heavy behavior into a modal instead.

## Usage guidance

- Do keep menu options short and distinct.
- Do keep the menu visually anchored to its trigger.
- Do separate destructive actions clearly inside the list.
- Don’t bury multi-step tasks inside a popover.
- Don’t use a popover menu when the action set is the primary content of the surface.

## Keyboard and accessibility

- Menu triggers should expose the correct expanded/collapsed state.
- Menus need an accessible label when the trigger alone is not sufficient context.
- Keyboard users should be able to reach the trigger and interact with the visible menu options predictably.
