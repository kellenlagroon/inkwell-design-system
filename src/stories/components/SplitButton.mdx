# SplitButton

A composite action control that keeps one dominant action visible while exposing a small set of related alternate actions.

**Status:** [Stable](?path=/docs/component-status-status--docs) · **Accessibility:** Meets standards

## When to use

- Use `SplitButton` when one creation path is primary but nearby alternates still need to be quickly available.
- Keep the primary action label stable and easy to scan.
- Use concise alternate labels with short descriptions.

## Usage guidance

- Do use split buttons for related alternate creation paths.
- Do keep the primary label as the dominant scan target.
- Do make alternate options feel meaningfully related to the primary action.
- Don’t use a split button when there is no clearly dominant action.
- Don’t overload the menu with a large or unrelated action set.

## Keyboard and accessibility

- The menu is a `Popover` in `menu` mode: ArrowDown opens it and focuses the first
  item, Arrow keys and Home/End move between items, Escape closes and returns focus
  to the trigger.
- Name the trigger with `menuLabel` — it describes what the menu contains and is the
  trigger's accessible name.
- The focused item shows a ring distinct from the hover fill.
- Alternate choices should remain understandable without relying on icon color alone.
