# Pill

A compact label primitive for short metadata, categories, and states. It owns the
shape and spacing; consumers can choose the visual treatment and colors.

**Status:** [Stable](?path=/docs/component-status-status--docs) · **Accessibility:** Meets standards

## When to use

- Use bordered pills for neutral or informational metadata such as roles and categories.
- Use borderless pills for lightweight state labels, including the recommended semantic tones.
- Keep the label concise and avoid sentence-length copy.

## Usage guidance

- Do use pills for short state tokens, not long explanations.
- Do use the recommended semantic tones when they communicate genuine status.
- Do use `appearance` and `colors` for product-specific metadata where a preset does not fit.
- Don’t overload pills with large amounts of text.
- Don’t use pills as the only way to communicate critical information.

## Keyboard and accessibility

- Pills are informational by default and should not masquerade as interactive controls.
- The text inside the pill should remain understandable without relying on color.
