# Drawer

A side sheet for focused workflows that should keep page context visible.

**Status:** [Beta](?path=/docs/component-status-status--docs) · **Accessibility:** Not reviewed

## When to use

- Use for edit, inspect, and filter flows that need more room than a popover.
- Use right-side drawers for detail/edit flows and left-side drawers for navigation-adjacent flows.
- Use `ModalFrame` when the task should fully interrupt the page.

## Usage guidance

- Do provide a specific title.
- Do keep close behavior predictable: Escape, backdrop, and close button.
- Don’t put app-specific workflow state in the drawer shell.

## Keyboard and accessibility

- The drawer uses `role="dialog"` and `aria-modal`.
- Focus moves into the drawer on open and returns after close.
- Tab focus is trapped while open.
