# Avatar

A compact identity mark showing an image or an initials fallback. Seeded from the
app's account avatar.

**Status:** [Stable](?path=/docs/component-status-status--docs) · **Accessibility:** Reviewed

## When to use

- Use to represent a person or entity in headers, lists, and menus.
- Provide `name` even when you pass `src` — it drives the initials fallback and the accessible label.
- Set `decorative` when the name is already shown next to the avatar.

## API

<ArgTypes of={AvatarStories} />

`name` drives the initials (up to two uppercase letters) and the accessible label.
`src` shows an image instead; `alt` defaults to `name`. `size` is `sm` | `md`
(default) | `lg`, and `shape` is `circle` (default) | `square`. Pass `children`
to supply a custom fallback such as an icon.

All avatars carry a subtle ring (an outlined offset outside the frame) — matches
the app's account trigger treatment. Set `interactive` (with `onClick`) to make
the avatar a button; the ring brightens on hover/focus.

## Keyboard and accessibility

- With initials (and not `decorative`), the mark is `role="img"` with an `aria-label` of the name.
- With an image, the `<img>` carries the `alt`; the wrapper adds no extra role.
- `decorative` hides the avatar from assistive tech (`aria-hidden`), for when the name is shown adjacently.
