## Summary

- **Stable:** 26 components — safe for production use, API stable.
- **Beta:** 6 components — usable but expect API adjustments as we validate them in real consumers.

**Accessibility:**

- **Reviewed** — manually verified in the browser (keyboard, focus, ARIA).
- **Baseline** — ships with baseline ARIA and keyboard support, but hasn't been through a dedicated audit.

Entries without a docs link are utility components re-exported from `ui.jsx`
without a dedicated `.mdx` page yet.
