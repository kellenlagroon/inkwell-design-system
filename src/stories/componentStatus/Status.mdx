## Summary

- **Stable:** 26 components — safe for production use; API stable.
- **Beta:** 19 components — usable but expect API adjustments as we validate them in real consumers.

**Accessibility**

- **Meets standards** — the component has been manually reviewed and passes Inkwell's accessibility criteria (keyboard navigation works, focus rings are visible, ARIA roles/labels are wired correctly). Safe to ship in an accessible experience.
- **Not reviewed** — the component ships with reasonable ARIA and keyboard defaults, but has not been through a dedicated audit yet. It may or may not pass — use with more caution and expect a review before it moves to Stable.

**Grouped docs pages** — some components share a docs page with a closely related one: `IconButton` sits inside the [Button](?path=/docs/components-button--docs) page, `EmptyState`, `Panel`, and `SectionHeading` live in [Surface](?path=/docs/components-surface--docs), and `ToastRegion` is documented alongside [Toast](?path=/docs/components-toast--docs). The "In X" links above jump straight to those parent pages.
