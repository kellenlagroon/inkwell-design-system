# Motion

Motion in Inkwell is about clarity, not spectacle.

- `motion-fast` for taps, hover shifts, and icon responses
- `motion-base` for controls, dropdowns, and banners
- `motion-slow` for larger surface changes when extra emphasis is useful

Reduced-motion preferences should always suppress decorative motion.
