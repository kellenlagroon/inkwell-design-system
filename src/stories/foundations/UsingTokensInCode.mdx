# Using Tokens In Code

Token usage should stay consistent between components, patterns, and page-level compositions.

## Guidance

- Reach for semantic color and surface variables first.
- Use spacing tokens for gap, padding, and margin decisions.
- Reuse typography and radius scales instead of introducing one-off values.

## Anti-patterns

- Hard-coding colors where a semantic token exists
- Creating new spacing values for one component
- Encoding meaning only through custom styling instead of shared tone conventions
