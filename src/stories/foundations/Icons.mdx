# Icons

Inkwell uses **Solar Linear** for product and interface icons, and **Simple
Icons** for third-party brand marks. This is one icon system: do not introduce
emoji or another UI-icon family.

## Approved library

The components exported from `components/icons.jsx` are the approved set. They
render in a 24 × 24 viewBox, default to `1em`, and inherit their color from the
surrounding component.

| Product icons (Solar Linear) | Brand icons (Simple Icons) |
|---|---|
| Arrow down, Award, Check, Close, Copy, More, Eye, File, List, Log in, Log out, Restart, Settings, Shirt, Trash, Trophy, Users | Google, Discord |

`BrandIcon` is the small compatibility chooser for a known sign-in provider:
`<BrandIcon id="google" />` renders Google, `<BrandIcon id="discord" />` renders
Discord, and other values fall back to the log-in icon. Prefer the named icon
exports in new code.

## Size and alignment

| Context | Size |
|---|---:|
| Dense controls and compact menus | 16px |
| Standard buttons, inputs, and navigation | 20px |
| Prominent empty states or feature callouts | 24px |
| Illustration-style treatment | 32px+; intentional exception |

- Icon-only buttons use 20px at the default size and 16px in compact controls.
- Keep the original SVG viewBox and proportions. Do not stretch an icon, alter
  its stroke width, or combine paths from different icons.
- Components should align icons optically with adjacent text. Icons inherit
  `currentColor`; use foreground tokens rather than hard-coded color values.

## Meaning, color, and accessibility

- Use an icon to reinforce an action or help scanning—not as decoration on
  every control.
- Use the same icon for the same meaning throughout the product. In particular,
  use `IconDotsVertical` for “more actions,” `IconClose` for dismissal, and
  `IconSettings` for settings.
- Use semantic foreground colors: default, muted, accent, success, warning,
  danger, or inverse. Disabled icons inherit the disabled state of their host.
- Never communicate status or a destructive action through an icon or color
  alone; pair it with text, a label, or another accessible cue.
- An icon-only button is appropriate only when its action is familiar in
  context. It must have an accessible name, such as
  `aria-label="Close dialog"`.
- In text buttons, put a leading icon before an initiating action and a trailing
  icon after a directional/progressive action.

## Brand marks

- Use Simple Icons only to identify the associated external service.
- Keep the official mark geometry. Use its native color only when recognition
  or a branded sign-in action calls for it; otherwise inherit the surrounding
  foreground color.
- Never use a brand mark as a generic action icon.

## Adding an icon

Request or add an icon only when the approved set does not express a stable,
repeated product concept. New interface icons must come from Solar Linear;
product-specific additions must use the same 24px grid, outlined construction,
rounded caps/joins, and visual weight. Record its source, upstream name,
version, and license in [the icon-system reference](../../../docs/icon-system.md).
